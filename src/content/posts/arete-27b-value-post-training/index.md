글·해설: 다메카솔

Nous Research가 공개한 Arete-27B는 Qwen3.8-27B의 답변 관점을 바꾸기 위해 추가 학습한 모델입니다. 공식 모델 저장소는 2026년 11월 6일 생성됐고, 11월 9일 현재 가중치와 모델 카드가 공개돼 있습니다. 개발사는 이를 서구적 가치를 강화하는 실험으로 설명합니다. 특정 평가에서 응답이 달라졌다는 결과와 보편적인 중립성을 얻었다는 판단은 구분해야 합니다.

## 모델을 처음부터 다시 만들지는 않았다

개발사는 Inkling이 만든 답변을 활용해 지도 미세조정(SFT)을 했다고 설명합니다. 원하는 응답 예시로 기존 모델을 추가 학습시키는 방식입니다. 강화학습이나 구조 변경은 쓰지 않았다는 보고입니다. 렌즈 그림은 관점이 달라지는 비유이며, 실제 모델 내부 구조를 그린 것은 아닙니다.

## 무엇을 좋아졌다고 측정했나

Nous가 만든 평가는 803개 질문에서 **정해 둔 사실을 답했는지**와 **중국 정부의 설명을 모델 자신의 입장으로 채택했는지**를 나눠 봅니다. Grok 4.7이 답변을 채점했고, 어떤 모델의 답변인지는 알려 주지 않았다고 합니다.

개발사 보고에서 추론을 끄고 온도 0으로 비교한 원본과 Arete의 사실 점수는 5점 만점에 2.32에서 2.98로 바뀌었습니다. 개발사가 정의한 선전성 응답 비율은 22%에서 0.9%로 줄었습니다. 각 모델에 같은 803개 질문을 다섯 번 제시하고 출력 상한을 32,000토큰으로 둔 결과입니다. 모든 정치적 편향을 측정한 비율도, 실제 이용자의 모든 질문에서 나온 비율도 아닙니다.

## 평가가 달라지면 질문도 달라진다

학습 목표와 평가 기준을 만든 주체가 같은 개발사입니다. 평가 질문, 채점 기준과 코드를 공개했다는 점은 외부 검증의 출발점이지만, 공개 자체가 독립 검증을 뜻하지는 않습니다. 이 글에서도 모델 실행이나 재현 실험은 하지 않았습니다.

다메카솔의 해석: 도입을 검토한다면 자체 업무의 질문으로 사실 누락·거절·답변 관점을 각각 살펴볼 필요가 있습니다. 이 실험이 보여 주는 것은 공개 가중치를 후학습해 응답 성향을 조정할 수 있다는 가능성입니다. 바뀐 관점이 모든 사용자에게 더 적절하다는 결론까지 대신 내려 주지는 않습니다.

## 직접 확인할 자료

- [Nous Research 발표](https://nousresearch.com/arete): 학습 목표와 개발사 평가 결과.
- [공식 모델 카드와 가중치](https://huggingface.co/NousResearch/Arete-27B): 공개 모델과 조건. 라이선스 표기는 Apache-2.0입니다.
- [평가 자료](https://huggingface.co/datasets/NousResearch/Propaganda_Eval): 질문·채점 기준을 확인하는 출발점. 학습 데이터와는 별개입니다.

발표일의 일 단위 근거는 [공식 저장소 메타데이터](https://huggingface.co/api/models/NousResearch/Arete-27B)의 생성 시각이며, 발표 블로그에는 2026년 11월까지만 표시돼 있습니다.
