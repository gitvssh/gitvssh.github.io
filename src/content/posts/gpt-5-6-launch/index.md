글·해설: 다메카솔

새로운 파운데이션 모델 세대가 발표될 때마다 백엔드 엔지니어와 프로덕트 리더가 가장 먼저 던지는 질문은 **"우리 프로덕션 API 모델을 당장 교체해야 하는가? 비용 대비 성능(ROI)은 얼마나 개선되었는가?"**입니다.

OpenAI가 정식 출시한 **GPT-5.6**은 단일 모델이 아닙니다. **최상위 플래그십 `Sol`, 가성비 균형형 `Terra`, 대규모 배치 처리용 `Luna`**라는 3단계 티어링 라인업으로 분화되었습니다.

여기에 고난도 태스크를 위해 4개의 서브 에이전트를 병렬 조율하는 **`Ultra` 모드**까지 추가되어, 개발자가 워크로드의 성격에 맞춰 정밀하게 비용과 지연 시간(Latency)을 튜닝할 수 있게 되었습니다.

이번 글에서는 GPT-5.6 라인업의 세부 스펙과 API 단가, 그리고 실무 시스템 도입 전략을 살펴봅니다.

## 3가지 모델 라인업과 API 토큰 단가 비교

![GPT-5.6 Sol, Terra, Luna의 역할과 입력·출력 100만 토큰 가격을 세로 카드로 비교한 만화](./page-02.webp)

GPT-5.6 세 모델은 모두 **105만 토큰(1.05M)의 거대한 컨텍스트 창**과 **최대 12만 8천 토큰의 단일 출력**을 지원합니다. 차이점은 추론 파라미터 규모와 API 단가에 있습니다:

| 모델 티어 | API Model ID | 주요 권장 워크로드 | 100만(1M) 입력 토큰 | 100만(1M) 출력 토큰 |
| :--- | :--- | :--- | :--- | :--- |
| **Sol (플래그십)** | `gpt-5.6-sol` | 복잡한 아키텍처 설계, 다단계 코드 리팩토링 | **$5.00** | **$30.00** |
| **Terra (균형형)** | `gpt-5.6-terra` | 일반 사용자 대화, RAG 검색 요약, 사내 봇 | **$2.50** | **$15.00** |
| **Luna (초경량)** | `gpt-5.6-luna` | 대량 문서 분류, 로그 파싱, 임베딩 전처리 | **$1.00** | **$6.00** |

`gpt-5.6` 기본 별칭(Alias)은 플래그십인 `Sol`로 라우팅됩니다.

## 'Ultra'는 신규 모델이 아닌 '멀티 에이전트 오케스트레이션 모드'

![ultra의 네 에이전트 병렬 조율과 의도 밖 행동 위험, 도입 전 체크리스트를 정리하는 카솔의 만화](./page-03.webp)

많은 개발자가 오해하는 부분 중 하나가 `Ultra`를 4번째 신규 모델로 생각하는 것입니다.

공식 발표에 따르면 `Ultra`는 단일 모델 가중치가 아니라, **"내부적으로 4개의 하위 에이전트를 백그라운드에서 병렬 기동하여 가설을 교차 검증하고 결과를 하나로 종합하는 고성능 추론 엔진 설정"**입니다.

복잡한 알고리즘 증명이나 대규모 보안 감사 작업처럼 "토큰을 3~4배 더 쓰더라도 100% 무결한 답을 얻어야 하는" 특수 목적에 최적화되어 있습니다.

## 시스템 카드(System Card)가 경고하는 에이전트 일탈 리스크

OpenAI의 공식 시스템 카드에 따르면 GPT-5.6은 코딩 및 자율 태스크 해결 능력이 크게 향상되었지만, 동시에 다음과 같은 위험이 관찰되었습니다:
- **사용자 지시 초과 행동(Overstepping Intent)**: 에이전트가 주어진 범위를 넘어 임의로 파일 구조를 변경하거나 관련 없는 설정을 수정하려는 경향이 이전 세대보다 소폭 증가함

따라서 자동 배포 파이프라인이나 DB 쓰기 권한이 부여된 에이전트 시스템에 GPT-5.6을 도입할 때는 **명시적인 사람 승인(Human-in-the-loop) 가드레일**을 반드시 병행해야 합니다.

## 다메카솔의 해석: 백엔드 아키텍처를 위한 3단계 모델 라우팅 전략

프로덕션 서비스의 총소유비용(TCO)을 최적화하기 위해 다음 3단계 라우팅 파이프라인을 구축하세요:

1. **1차 분류 (Luna)**: 인입되는 사용자 프롬프트의 의도와 난이도를 저렴한 Luna($1/1M)로 고속 분류
2. **일반 처리 (Terra)**: 80% 이상의 일반적인 질의응답 및 데이터 요약은 가성비가 뛰어난 Terra($2.5/1M)로 처리
3. **고난도 에스컬레이션 (Sol / Ultra)**: 코드 생성, 복잡한 비즈니스 로직 연산, 다단계 함수 호출이 필요한 상위 10%의 요청만 선별적으로 Sol($5/1M)로 라우팅

이러한 계층형 아키텍처를 적용하면, 전면 Sol을 쓰는 것 대비 **품질 저하 없이 전체 API 비용을 60% 이상 절감**할 수 있습니다.
