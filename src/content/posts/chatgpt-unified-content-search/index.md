지난주에 만든 대화나 업로드한 문서를 다시 찾으려고 사이드바와 프로젝트, 파일 보관함을 번갈아 본 적이 있다면 이번 변화가 반갑습니다. **OpenAI는 2026년 7월 14일 ChatGPT에서 과거 대화·프로젝트·이미지·문서를 한곳에서 찾는 통합 검색을 출시했습니다.** 웹·iOS·Android의 모든 요금제에 전 세계 제공된다고 공식 릴리스 노트에서 밝혔습니다.

글·해설: 다메카솔

## 핵심 내용

- ChatGPT 사이드바의 한 검색 입구에서 대화, 프로젝트, 이미지, 문서를 찾을 수 있습니다.
- 콘텐츠 유형 필터로 범위를 좁히고 결과를 선택해 해당 작업물을 바로 열 수 있습니다.
- 이 기능은 내 ChatGPT 자료를 찾는 검색입니다. 외부 최신 정보를 찾는 ChatGPT 웹 검색과 목적이 다릅니다.
- OpenAI는 검색 알고리즘이나 정확도 개선 폭, 색인 지연 시간은 공개하지 않았습니다.

## 여러 검색 입구가 사이드바 한곳으로 모였다

![흩어진 대화, 프로젝트, 이미지, 문서가 하나의 사이드바 검색과 콘텐츠 유형 필터로 정리되는 전후 변화](./page-01.webp)

이번 업데이트의 핵심은 새로운 답변 모델이 아니라 **이미 만들어 둔 작업물을 다시 찾는 경로가 합쳐졌다는 것**입니다. OpenAI 공식 릴리스 노트에 따르면 사용자는 ChatGPT 사이드바에서 검색을 시작하고, 콘텐츠 유형 필터로 결과를 좁힌 뒤 원하는 대화·프로젝트·파일을 직접 열 수 있습니다.

발표 기준 지원 범위는 다음과 같습니다.

| 항목 | 발표된 범위 |
| --- | --- |
| 검색 대상 | 대화, 프로젝트, 이미지, 문서 |
| 플랫폼 | 웹, iOS, Android |
| 요금제·지역 | 모든 ChatGPT 요금제, 전 세계 |
| 결과 동작 | 선택한 대화, 프로젝트 또는 파일 열기 |

Library 도움말에는 파일 검색을 업로드한 파일과 생성한 파일로 구분하고, 이미지·문서·스프레드시트·프레젠테이션·PDF 같은 파일 유형으로 좁힐 수 있다고 설명돼 있습니다. 다만 계정·워크스페이스 정책이나 보관 상태에 따라 실제로 보이는 자료 범위는 달라질 수 있습니다.

## 내 자료 검색과 웹 검색은 목적이 다르다

![내 자료 검색과 웹 검색의 대상을 두 갈래로 구분하고 카솔이 콘텐츠 유형 필터 사용을 안내하는 만화](./page-02-v2.webp)

둘 다 `검색`이라는 이름을 쓰지만 찾는 대상이 다릅니다.

| 필요한 것 | 사용할 검색 |
| --- | --- |
| 예전에 나눈 대화, 프로젝트, 업로드·생성한 파일 | 사이드바 통합 검색 |
| 뉴스, 공식 문서, 현재 가격처럼 외부의 최신 정보 | ChatGPT 웹 검색 |

ChatGPT 웹 검색은 외부 검색 제공자와 웹 정보를 이용해 최신 답변과 출처 링크를 제공하는 기능입니다. 반면 이번 통합 검색은 내 ChatGPT 작업물을 다시 찾아 여는 탐색 기능입니다. 따라서 원하는 결과가 많다면 먼저 `대화`, `프로젝트`, `이미지`, `문서` 같은 콘텐츠 유형으로 범위를 좁히는 것이 가장 직접적입니다.

## 발표만으로는 알 수 없는 것

OpenAI는 이번 릴리스 노트에서 검색 대상, 필터, 지원 플랫폼과 요금제는 설명하지만 다음 내용은 공개하지 않았습니다.

- 검색 알고리즘이 어떻게 바뀌었는지
- 검색 정확도가 이전보다 얼마나 개선됐는지
- 새 대화나 파일이 검색 결과에 잡히기까지 걸리는 시간
- 제목·본문·파일 내용 중 무엇을 어떤 방식으로 일치시키는지

그래서 `검색이 더 정확해졌다`거나 `모든 파일 내용이 검색된다`고 확대해서 말할 근거는 아직 없습니다. 현재 확인 가능한 변화는 **흩어진 내 ChatGPT 작업물을 한 검색 입구에서 찾고, 유형별로 좁혀 다시 열 수 있게 됐다**는 범위까지입니다.

## 사용 전에 기억할 세 가지

1. 찾는 것이 내 작업인지 외부 최신 정보인지 먼저 구분합니다.
2. 결과가 많으면 대화·프로젝트·이미지·문서 필터로 좁힙니다.
3. 보이지 않는 자료가 있다고 해서 삭제됐다고 단정하지 말고 계정, 프로젝트, 워크스페이스 보관 정책을 함께 확인합니다.

## 자주 묻는 질문

### 무료 요금제에서도 사용할 수 있나요?

OpenAI의 2026년 7월 14일 발표 기준 모든 ChatGPT 요금제에 전 세계 제공됩니다.

### ChatGPT 웹 검색을 대체하나요?

아닙니다. 통합 검색은 내 ChatGPT 대화·프로젝트·파일을 다시 찾는 기능이고, 웹 검색은 외부 최신 정보를 출처 링크와 함께 찾는 기능입니다.

### 검색 결과가 더 정확해졌나요?

OpenAI는 새 검색을 출시했다고 밝혔지만 정확도 개선 폭이나 검색 알고리즘 변화는 공개하지 않았습니다. 실제 품질은 별도로 확인해야 합니다.
