글·해설: 다메카솔

OpenAI는 2026년 11월 17일 GPT-6.2 Astra와 Sol을 발표했습니다. Astra는 복잡한 전문 프로젝트, Sol은 일상 업무를 위한 모델로 소개했습니다. 아래는 11월 18일 확인한 공식 발표 기준이며, 직접 성능을 비교한 사용기는 아닙니다.

## 작업을 보고 두 모델을 구분하기

OpenAI는 Astra의 문서·슬라이드·스프레드시트 작성과 코드 구현 능력이 개선됐다고 설명합니다. Sol은 여러 단계를 거치는 일상 업무를 효율적으로 처리하는 모델로 제시했습니다. 두 모델 모두 출력 토큰을 덜 쓰면서 더 나은 결과를 낸다는 설명은 회사의 주장입니다. 모든 업무에서 같은 효과를 보장하는 독립 검증 결과로 읽으면 안 됩니다.

![뒤섞인 업무를 살피던 독자가 카솔과 함께 일상 업무와 복잡한 프로젝트를 구분하는 비유](./page-01.webp)

그림의 업무 묶음과 설계물은 두 역할을 구분하기 위한 비유입니다. 실제 제품 화면이나 실행 결과를 재현한 그림이 아닙니다. 다메카솔의 해석: 모델 이름만 보고 결정하기보다, 자주 하는 작은 작업과 검토가 많이 필요한 프로젝트를 나눠 같은 입력으로 결과를 비교하면 선택 기준을 세우기 쉽습니다.

## 제공 범위와 남아 있는 조건

발표는 ChatGPT Work와 Codex에서 Plus·Pro·Enterprise·Edu 사용자에게 두 모델을 제공한다고 안내합니다. API 모델 이름은 `gpt-6.2-astra`와 `gpt-6.2-sol`입니다.

Ultrafast는 별도 조건이 있습니다. Pro 500은 두 모델, Pro 200은 Sol부터 제공하며, 해당 Enterprise·Edu 사용자는 관리자 활성화가 필요하다고 설명합니다. API에서는 두 모델 모두 출시 시점부터 Ultrafast를 제공한다고 밝혔습니다. 이 글에서는 특정 계정의 메뉴 노출이나 응답 속도를 시험하지 않았습니다.

OpenAI는 GPT-6.2의 Daybreak 도입을 향후 계획으로 적었습니다. 현재 ChatGPT·Codex·API 제공 안내와 구분해야 합니다. 이전 모델의 보안 접근 조건은 [GPT-6 Astra와 보안 통제 해설](/posts/openai-astra-cyber-capability-controls/)에서 별도로 다룹니다.
