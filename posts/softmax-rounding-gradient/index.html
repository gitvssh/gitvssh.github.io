AI가 확신할수록 학습 신호가 사라지는 이유: softmax의 반올림

이 글에서 얻는 것

softmax와 cross-entropy의 반올림은 어떻게 학습 신호를 바꿀까요? 작은 기울기 소실과 증류의 잔여 기울기를 구분하고 논문의 실험 범위를 살펴봅니다.

분류 모델의 예측이 정답에 바짝 가까워지면 학습 신호도 자연스레 작아집니다. 그런데 부동소수점 계산 도중 그 작은 값이 0으로 반올림되면, 아직 필요한 신호가 너무 일찍 사라질 수 있죠. 「A Fix for Softmax and Cross-Entropy」는 확신이 큰 정답의 기울기가 사라지는 문제와, 반대로 같아진 두 분포 사이에 가짜 기울기가 남는 문제를 구분해 계산식을 바로잡는 방법을 제안합니다.

글·해설: 다메카솔

작은 차이가 왜 학습 방향을 바꿀까요

모델이 각 선택지에 매긴 점수를 logit이라고 부르며, softmax는 이를 확률 분포 q로 바꾸고 cross-entropy는 목표 분포 p와의 손실을 계산합니다. 정확한 산술에서 logit 기울기는 q−p이며 이 값들을 모두 더하면 합이 0이 됩니다. 물론 이 합이 0이라는 성질은 최종 logit 기울기에만 해당하며, 모델 전체 매개변수의 기울기 합을 뜻하지는 않습니다.

예를 들어 모델이 정답을 강하게 확신해 확률이 1에 가까워지면 정답 쪽 기울기 q−1은 아주 작은 음수가 됩니다. 논문이 먼저 짚는 문제는 이 작은 음수만 0으로 반올림되어 사라지는 사이 오답 쪽의 양수 기울기는 그대로 남는다는 데 있거든요. 학습 신호 전체가 한꺼번에 꺼진다고 보면 균형이 깨지는 핵심 원인을 놓치기 쉽습니다.

큰 값에 더하는 순간 작은 값이 사라집니다

정답 점수가 가장 큰 경우를 생각해 봅시다. 논문은 정답 logit에서 나머지 점수들의 log-sum-exp를 뺀 차이를 margin m으로 정의하며, 정답 쪽 기울기는 수학적으로 똑같은 두 식으로 쓸 수 있습니다.

기존 형태: 1 / (1 + exp(-m)) - 1
수정 형태: -exp(-m) / (1 + exp(-m))

두 식은 수학적으로 같지만 exp(−m)이 아주 작아지면 컴퓨터 계산이 갈립니다. 부동소수점 산술에서 1+exp(−m)이 정확히 1로 반올림되면서 기존 식은 결국 1−1이 되어 작은 음수를 통째로 잃거든요. 반면 수정 식은 작은 값 −exp(−m)을 분자에 남겨 두므로 분모가 반올림돼도 정답 기울기를 지킵니다. 다만 지수 자체가 표현 범위를 벗어나는 underflow 한계는 남습니다.

실제 구현도 수식 변형에서 한 걸음 더 나아갑니다. 저자들은 log-sum-exp와 수치적으로 안정적인 softplus를 조합해 역전파에서도 작은 값이 보존되는 계산 경로를 구성했습니다. log(1+exp(x))를 그대로 계산하면 덧셈에서 같은 정밀도 손실이 되살아나기 때문이죠.

논문이 분석한 반올림 경계는 확률이나 단일 logit이 아니라 앞서 정의한 margin m 기준이며, 정밀도를 높여도 경계가 뒤로 밀릴 뿐 유한 정밀도 조건은 남습니다.

정밀도 반올림 경계 (margin m)
bf16 약 5.5
fp32 약 16.6
fp64 약 36.7

논문의 fp32 JAX 예제는 작은 음수 하나의 소실이 기울기 균형을 어떻게 깨는지 잘 보여 줍니다.

  • 입력: fp32 logit [9, −9, −9], 첫 번째 항목이 정답입니다.
  • 기울기 비교: 기존 식의 정답 기울기는 0으로 사라지지만 수정 식은 약 −3.046×10⁻⁸을 유지하며, 나머지 두 오답 기울기는 각각 약 1.523×10⁻⁸로 남습니다.

같아진 교사와 학생이 다시 멀어지는 문제

지식 증류에서는 반대로 없어야 할 신호가 남는 문제가 생깁니다. 가령 학생 모델이 교사 분포를 완벽히 따라잡아 두 모델의 logit이 같아졌다고 해 봅시다. 차이가 없으니 가중치를 움직일 기울기도 0이어야 정상이죠.

그런데 교사 확률을 만드는 순전파 softmax와 역전파 log-softmax의 계산 경로가 다르면 끝자리 오차가 어긋나며 잔여 기울기가 남을 수 있습니다. 똑같이 저장된 두 부동소수점 값을 단순 뺄셈해서 오차가 난다는 설명과 달리, 같은 입력이 서로 다른 연산 경로를 지나며 갈라지는 현상입니다.

연구진은 학생과 교사의 logit 차이를 먼저 취한 뒤 expm1과 log1p로 작은 차이를 정밀하게 다루는 별도 soft-target 방법을 제안했습니다. 첫 문제가 필요한 작은 신호를 살리는 작업이라면, 둘째 문제는 거의 같은 값의 차이를 정확히 구해 가짜 잔여 신호를 줄이는 셈이죠.

fp32와 기본 epsilon에서는 수정 식이 불안정성을 없애며 만점에 도달했습니다. 반대로 epsilon을 더 낮추면 수정 식도 100% 아래로 내려오고, fp64에서는 기존 식도 만점을 기록하거든요. 논문 표에 ± 정의가 없어 신뢰구간이나 표준편차로 단정하지 않고 원문 표기를 유지했으며, 모든 정밀도와 설정에서 정확도가 오른다고 일반화하기는 어렵습니다.

증류 실험은 새 학생의 성능 향상보다, 교사와 같아진 학생이 수치 오차로 이탈하지 않는지 살피는 점검에 가깝습니다.

  • 실험과 결과: 두 수를 더해 53으로 나눈 나머지 과제에서 정확도 100% 교사 가중치를 학생에 복사해 temperature 4, Adam 2,000 step, 학습률 0.002, weight decay 0, epsilon 10⁻⁸로 학습했습니다(3개 seed 중 2개를 그림에 표시). 기존 bf16에서는 학생이 이탈했고, 수정 식은 초기 상태를 유지했다고 보고합니다.

다메카솔의 해석: 식과 계산 경로를 함께 봅니다

저자들도 극단적인 margin이나 거의 같은 교사·학생 조건이 일반 대규모 학습에서는 흔하지 않다고 적습니다. 작은 산술 과제 중심의 검증이라 대규모 모델의 성능이나 전체 학습비 절감까지 입증했다고 보기는 어렵습니다.

Jonathan T. Barron, Dan Gnanapragasam, Michael Tschannen이 2026년 10월 22일 제출한 v1 프리프린트와 프로젝트 페이지에는 JAX 예제가 공개돼 있지만, 전체 실험을 담은 별도 저장소나 동료심사 통과 여부는 확인되지 않았습니다.

그래도 실무 개발자가 가져갈 관점은 분명한 편입니다. 수학적으로 같은 식이라도 유한 정밀도와 연산 경로가 다르면 다른 학습 신호가 나올 수 있습니다. 특정 라이브러리 버전의 수정 완료를 전제하기보다, 사용 중인 dtype, 커널, 손실 함수, 역전파 경로에 작은 극단 입력을 직접 넣어 기울기를 점검해 볼 만합니다.
