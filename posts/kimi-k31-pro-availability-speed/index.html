Kimi K3.1 Pro 출시, 이용 조건과 Highspeed의 범위

이 글에서 얻는 것

Kimi K3.1 Pro의 서비스 이용과 가중치 공개 예정일을 구분하고, Highspeed의 출력 속도·사용량·실행 조건을 살펴봅니다.

Kimi는 2026년 10월 23일 K3.1 Pro와 K3.1 Pro Highspeed의 Kimi Code 제공을 발표했습니다. 모델을 서비스에서 쓰는 시점과 가중치를 내려받는 시점은 다릅니다. 공식 발표는 Kimi.ai·Kimi Work·Kimi Code·API에서 이용할 수 있다고 안내하면서, 전체 가중치는 11월 4일까지 공개할 예정이라고 밝혔습니다. 10월 25일 확인한 발표 기준이며, 이 글에서는 가중치 배포 완료로 해석하지 않습니다. 공식 릴리스 노트 · 모델 발표

글·해설: 다메카솔

Kimi Code에서는 요금제와 모델 ID를 함께 확인합니다

공식 문서상 일반 K3.1 Pro는 Plus 또는 기존 Moderato 이상에서 제공됩니다. 최대 1M 컨텍스트와 Highspeed는 Pro 또는 기존 Allegretto 이상 조건이 붙습니다. 여기서 컨텍스트는 모델이 한 번에 다룰 수 있는 입력·대화 범위입니다. 이 조건은 Kimi Code에 관한 것으로, 다른 제품의 요금제나 API 과금까지 같은 조건이라고 확대하지 않습니다.

모델 ID는 k3.1-pro와 k3.1-pro-highspeed입니다. 문서는 새 모델로 옮길 때 새 세션을 시작하고 thinking을 켜 두라고 안내합니다. K3.1 Pro는 thinking을 끈 요청을 거부하며, 잘못된 모델 ID는 K2.8 Preview의 thinking 없는 경로로 넘어갈 수 있다고 설명합니다. 모델 이름을 바꿨다는 사실만으로 원하는 실행 조건이 맞았다고 판단하기 어렵습니다. 모델 설정 문서

Highspeed가 빨라지는 구간

Kimi는 Highspeed가 일반 Pro와 같은 모델 능력을 제공하면서 약 2~3배의 속도를 낸다고 설명합니다. 이는 제공사의 주장으로, 이번 글에서 독립적으로 측정한 결과가 아닙니다. Kimi Code 문서는 Highspeed의 사용량 차감도 일반 Pro의 약 2배라고 안내합니다.

문서가 한정하는 가속 대상은 모델 출력입니다. 파일을 읽고 쓰거나 명령·스크립트를 실행하는 시간은 그대로 남습니다. 도구 실행이 긴 작업이라면 모델의 출력 속도 차이가 전체 완료 시간에 같은 비율로 나타나지 않을 수 있습니다. Highspeed 설명과 FAQ

다메카솔의 해석으로는, 모델을 바꿔 볼 때 완료까지 걸린 시간과 사용량 차감을 함께 비교하는 편이 유용합니다. 출력 대기가 길었던 작업인지, 테스트나 빌드가 오래 걸렸던 작업인지에 따라 얻는 이점이 달라지기 때문입니다. 이 글은 제품을 직접 실행한 사용기가 아니며, 성능·가격의 우열이나 구매를 결론내리지 않습니다. 모델 이름에 담긴 기대와 실제 실행 조건을 나눠 보는 관점은 Bolt E4B의 메모리 조건에서도 이어집니다.
