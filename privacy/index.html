방문 분석 및 개인정보

이 블로그는 콘텐츠와 유입 채널을 개선하기 위해 Cloudflare Web Analytics와 Google Analytics 4를 선택적으로 사용합니다. 방문자가 분석을 허용하기 전에는 두 서비스의 분석 스크립트를 불러오지 않습니다.

수집하는 정보

허용 후에는 방문 페이지, 유입 캠페인, 글 읽기 진행과 내부 링크 클릭 같은 이용 이벤트를 수집할 수 있습니다. Cloudflare에서는 페이지 방문과 웹 성능에 관한 기본 통계를, Google Analytics에서는 유입 경로와 콘텐츠 이용 이벤트를 확인합니다. 이름, 이메일, 계정 ID나 자유 입력문 같은 개인 식별 정보는 사용자 정의 이벤트로 전송하지 않습니다.

선택 저장과 변경

분석 선택은 현재 브라우저의 로컬 저장소에 보관됩니다. 페이지 하단의분석 설정에서 선택을 다시 열고 분석을 중단할 수 있습니다.

외부 서비스

Cloudflare와 Google의 데이터 처리 방식은 각각Cloudflare 개인정보처리방침과Google 개인정보처리방침에서 확인할 수 있습니다. 광고 저장과 광고 개인화는 이 블로그의 Analytics 설정에서 비활성화합니다.

복잡한 기술을 만화와 정확한 글로 설명합니다.
